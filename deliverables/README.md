# Included demo and design references

- **`zonhack-demo.html`** — latest self-contained demo: graph-only Overview, year/week/month comparisons, right-side date panel, marketplace and All/Single/Parent SKU controls, specialist modules and exports. Download the raw file and open it in a modern browser. GitHub's source viewer displays HTML source; it does not run the application.
- **`previews/`** — current dark-theme Overview and its marketplace/SKU menus.
- **`history/`** — earlier screenshots documenting the progression from the first Explorer to the accepted layout. These are historical references, not the current design target.

All business data is synthetic. The editable application is in the source folders at the repository root. Start with [`DEVELOPER_HANDOFF.md`](../DEVELOPER_HANDOFF.md) for setup, tests, source locations, publishing instructions and remaining production work.
